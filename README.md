# Out of Scope

## Short Description

Out of Scope challenges the [W3C's One Web Ethical Web Principle](https://www.w3.org/TR/ethical-web-principles/#oneweb), which says that there is one web that should be freely accessible across regions and cultures. The film and writing explores the history, politics, and culture that led us to the creation of the web, and asks: what if the web was Yoruba?

## Long Description

Out of Scope engages with Netstalgia by challenging the foundational principles of the web and the World Wide Web Consortium (W3C), the standards body for the web. One of the ethical principles of the web is that there is one web that should be accessible across regions and cultures, this principle assumes that the architecture of the web is neutral. Out of Scope interrupts this myth by interrogating the historical, political and cultural conditions that create the web we have today. I ask 'what if the web was Yoruba?' by looking at Yourba knowledge systems, technology and history, and speculating about how a Yoruba web could work architecturally.

Out of Scope doesn’t assume a Yoruba web would be better, rather I want to challenge the audience to consider assumptions that exist in the making of the web and encourage them to think of alternative webs.

## Bio

Lola is a multidisciplinary artist and web standards technologist. She is curious about alternative forms of navigating and experiencing the web. Her work ‘*What Do You See?: Alt Text as Artistic Medium’* asked an audience to reconsider their definition of an “image” and explore alternative forms for presenting the visual. She leads the Accessibility Compat Data project which aims to make accessibility data more visible to web developers, and she is currently co-chairing the W3C Technical Architecture Group.
